# THE ANONYMOUS SURFACE OF THE FLEET — every path reachable without a token.
#
# One line per (service, matcher). ops/security/security_config_drift.py reads
# this and fails when a SecurityConfig opens something this file does not
# declare, or declares something the config no longer opens.
#
# This file does NOT assert that everything below is correctly public. Several
# entries are deliberate and documented in their own config: a guest cart's
# random id is its bearer secret, the public catalog is readable by design, the
# TS.43 door answers handsets before they have an account. What it asserts is
# that the set cannot GROW by accident. Adding a line is the deliberate act,
# and it belongs in the same commit as the config change, with the reason in
# the config's own comment.
#
# Generated from the code as it stood when the check was written, not typed
# from memory. 253 entries, 39 services.
#
# Five appear in nearly every component and are infrastructure, not API:
#   /actuator/health/**  /actuator/prometheus   (probes and scraping)
#   /v3/api-docs/**  /swagger-ui/**  /swagger-ui.html   (discovery)
#
# FRAMEWORK-SERVED PATHS (#428), written "framework:<path>". These have NO
# permitAll line: a Spring Security filter answers them itself, BEFORE the
# authorization filter runs, so reading the configs could never find them.
# They were MEASURED, not inferred: FrameworkSurfaceTest (agreement, ontology)
# boots the real filter chain and probes, and on 3 Nov 2026 every running
# component on the laptop fleet answered both without a token. Two, in every
# component that has a SecurityConfig:
#   framework:/.well-known/oauth-protected-resource/**   GET -> 200
#       OAuth2ProtectedResourceMetadataFilter, switched on by oauth2ResourceServer()
#       since Spring Security 7 with no switch to turn it off. An RFC 9728
#       document naming the pod's own URL and no authorization server; only the
#       ontology fills it in, and only the ontology's MCP document is routed by
#       the gateway.
#   framework:/logout                                    any method -> 302
#       LogoutFilter, on in every HttpSecurity unless .logout() is disabled;
#       any method because CSRF is off. Stateless, so there is nothing to log
#       out: it clears an empty context and redirects to a /login that does
#       not exist (401).
# The drift check requires every copy with the measured configurer shape to
# declare exactly the framework paths the measured reference (agreement)
# declares, and refuses a configurer the probe has never measured.
