# THE SEED PATH: an empty fleet to the state the suites assert on.
#
# Read by ops/seed-fleet.sh (which runs it) and ops/arch/seed_coverage_check.py
# (which holds it against what the suites actually assert on). One file, so the
# runner and the gate cannot disagree.
#
# WHY THIS EXISTS. The order used to live in two places and neither was
# runnable: ops/README.md documented 13 of 54 scripts in prose, and
# .github/workflows/browser-proof.yml carried a 22-script list inside the
# nightly job. That job is gated on `vars.BROWSER_PROOF_RUNNER`, which has
# never been set, so every scheduled run reports "skipped" — the 22-script
# order had never once executed. Meanwhile the laptop's fleet state was
# ACCUMULATED by hand, which is why the committed proof run sat at 122 of 258
# suites since 24 September and could not be reproduced anywhere. Issue #261.
#
# FORMAT:  <tier>  <script>  [args...]
#   smoke  also run by the PR smoke tier (keep it small — it blocks every PR)
#   full   the whole path, for a proof run
#
# ORDER MATTERS in three places, and only three, all recorded where they bite:
#   - seed_genalpha_one before reshape_bundle before link_prices: the bundle is
#     reshaped and then priced.
#   - seed_content AFTER seed_nova: it writes artwork for both tenants' catalogs.
#   - seed_service_specifications and seed_resource_facing_services LAST: they
#     stamp the CFS/RFS chain onto whatever specs the other seeds left sellable,
#     and the bundle seed re-points specs.
# Everything else is independent as far as I could determine by reading them;
# where that turns out to be wrong, the fix is a line move here, not a hunt.
